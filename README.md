# Electricity Billing System

A Java-based desktop application to manage electricity customers, meter readings, bill generation, and payment status.  
Designed using **Java Swing & AWT**, connected with **MySQL database** for secure data handling.



## 🚀 Features

✔ Login & Signup system with Splash screen  
✔ Add and manage customer details  
✔ Meter information management  
✔ Generate monthly electricity bills  
✔ View and update payment status  
✔ Secure Java-MySQL connectivity


## 🛠 Tech Stack

Technology Usage 

Java (Swing, AWT)
UI and business logic
MySQL for Database
NetBeans IDE for Development
JDBC Driver for Database connectivity
